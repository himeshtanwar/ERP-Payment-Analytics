# ERP Payment Analytics Dashboard

## 📌 Project Overview

This project analyzes ERP payment transaction data using SQL and Power BI. The objective is to gain business insights into payment trends, vendor performance, bank-wise transactions, and payment processing status.

---

## 🛠️ Tools Used

- PostgreSQL
- SQL
- Microsoft Power BI
- Microsoft Excel

---

## 📂 Dataset

The dataset contains ERP payment transaction records with details such as:

- Payment Reference Number
- Branch Code
- Vendor Code
- Beneficiary Name
- Payment Amount
- Payment Date
- Bank Name
- City
- Processing Status
- Failure Reason

---

## 📊 Dashboard Features

The dashboard includes:

- Total Payment Amount
- Total Transactions
- Total Vendors
- Total Banks
- Payment Trend by Date
- Top 10 Vendors
- Bank-wise Payment Analysis
- Payment Status Distribution
- Daily Transaction Trend

---

## 📝 SQL Analysis

The project includes SQL queries for:

- Total payment amount
- Bank-wise payment analysis
- Vendor-wise payment analysis
- City-wise transaction count
- Monthly payment trend
- Top 10 vendors
- Ranking using Window Functions
- Running Total
- Duplicate transaction detection
